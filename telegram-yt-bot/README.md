# 🎬 Y-V Downloader Bot 🤖

A powerful Telegram bot that allows users to download YouTube videos and songs directly in **audio 🎧 or video 🎬 format** with fast performance and smart UX.

---

## 🚀 Features

✅ Download YouTube videos via link  
✅ Search songs using `/song <name>`  
✅ Choose format (Audio 🎧 / Video 🎬)  
✅ Fast downloading using yt-dlp  
✅ Auto delete temp files (no storage issue)  
✅ MongoDB user tracking  
✅ Search history feature (`/history`)  
✅ Smart UI with buttons  
✅ Contact-based onboarding  

---

## 🧠 Tech Stack

- Node.js
- Telegram Bot API (`node-telegram-bot-api`)
- yt-dlp (`yt-dlp-exec`)
- MongoDB + Mongoose
- dotenv
